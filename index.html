Studio Gambar & Video

Dibuat oleh model Google (Nano Banana untuk gambar, Veo untuk video). Kunci API Anda tersimpan aman di server — tidak pernah tampil di sini.

Buat Gambar

Pilih contoh cepat atau tulis sendiri. Untuk hasil rapi, sebutkan gaya: “clean vector illustration, cherry-blossom pink palette, children's-book style, white background, no text”.

Buat Video

Eksperimental — lambat (beberapa menit) & memakai lebih banyak kredit. Pakai seperlunya.

Veo membuat klip pendek (sekitar 8 detik). Sebutkan gerak kamera dan suasana.

Kunci API hanya tersimpan di Environment Variables Vercel (server), tidak pernah dikirim ke browser. Jangan pernah menempelkan kunci di percakapan chat. Biaya memakai kredit Google Anda: gambar relatif murah; video (Veo) jauh lebih mahal.
